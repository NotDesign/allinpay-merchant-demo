# AllinPay Merchant Demo

依照指定 8 個 Figma 畫面製作的靜態 HTML / CSS / JavaScript 互動原型，介面以繁體中文呈現。

## 開啟

下載整個 Repository（Code → Download ZIP），解壓縮後開啟 `index.html`，不需要安裝 Node.js 或任何套件。

亦可在資料夾執行 `python3 -m http.server 8765`，瀏覽 `http://localhost:8765`。瀏覽器的草稿儲存空間會隨網址而不同。

## 建議 Demo 流程

1. 儀表板 → 新增商戶 →「填入完整示例」。
2. 逐步修改資料；步驟列可返回任何步驟，下一步會驗證當前必填欄位。
3. 聯絡電郵可演示驗證：輸入任意示例電郵，驗證碼固定為 `123456`，不寄送郵件。
4. 文件材料列出全部 27 個文件項目，支援選取／重新選取／移除 JPG、PNG、ZIP，單檔上限 10 MB。
5. 儲存草稿，從側欄「已儲存的草稿」重新開啟。可重新整理頁面後測試還原。
6. 確認提交頁查看同步摘要及返回修改；勾選聲明後產生模擬申請編號。
7. 勾選頁面上方「模擬儲存／提交失敗」，測試失敗 Overlay 及內容保留，關閉該選項後可重試。
8. 商戶管理可跨欄位搜尋、篩選狀態、分頁、原位顯示／隱藏銀行帳號、查看／帶入編輯、批次模擬同步。

## 刻意保留的界線

- 此為前端原型，不是正式商戶系統；沒有登入、後端授權、OCR、KYC、風控、真正的電郵驗證、銀行驗證或 All-In Pay API。
- 不要輸入真實身份證、銀行帳號、密碼或客戶文件。所有畫面資料僅供演示。
- 上傳按鈕只讀取本機檔名及大小，不傳送檔案。草稿保存檔名，不保存二進位內容；重新載入草稿後，真實選取的附件需重選。示例附件清楚標記為未上傳。
- 草稿存於目前瀏覽器 localStorage，沒有加密、跨裝置同步或伺服器備份。只有點擊「儲存草稿」才會寫入，不宣稱自動儲存。
- 表格前 5 筆來自 Figma 的模擬資料，其餘 115 筆清楚標示示例，用來演示原設計的 24 頁分頁。儀表板待辦數字是設計中的固定示例，不是由列表即時計算。
- 香港銀行搜尋清單只提供示範銀行，並非官方完整清單。國家／地區連動也為示例資料。
- 基本欄位與部分條件驗證已實作；正式系統仍需完整商業規則、官方地區／MCC／銀行資料、權限與伺服器端驗證。
- 帳號管理、批量導入等不是這次指定的 8 頁，點擊會說明範圍。商戶詳情及商戶轉換為補足基本流程的簡化對話框，不宣稱完整還原其他 Figma 畫面。
- 發佈靜態網站後，訪客可檢視下載 HTML、CSS、JS 和隨站示例資料，即使 GitHub Repository 是私人。不索引並不等於存取控制。

## 驗證

執行 `node verify.cjs`，驗證所有來源欄位／文件／產品控制項存在、基本條件校驗、草稿成功／失敗／還原、搜尋與本機素材。`node --check app.js` 檢查語法。

額外以實際瀏覽器人工驗證六步導覽、錯誤狀態、草稿 Overlay、確認摘要及提交流程。桌面版以 Figma 共用 Sidebar、欄位、卡片及按鈕規格為基礎，窄螢幕調整為單欄或雙欄，不截斷長表單。

## 檔案

- `index.html`：入口
- `styles.css`：共用視覺樣式與響應式版面
- `app.js`：路由、表單與互動
- `data.js`：來源驅動的欄位與內容
- `verify.cjs`：零依賴測試
- `source-figma.json`：來源快照
- PNG / SVG：下載的 Figma 素材

目前 Repository 為私人。沒有啟用 GitHub Pages，也沒有建立公開網站。網站分享的可見性需另行設定。
